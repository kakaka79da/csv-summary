# 실사풍 캐릭터 초상 에셋

이 폴더에 아래 파일을 넣으면, 카드·면담·직원 패널의 캐릭터가 자동으로 실사 이미지로
바뀝니다. 파일이 없으면 SVG 스프라이트로 그대로 표시되며 오류는 나지 않습니다.

| 파일명 | 캐릭터 |
|---|---|
| `elena.png` | 엘레나 · 총무 매니저 (전술 서기관) |
| `kyle.png` | 카일 · 수석 연구 엔지니어 (룬 마법공학자) |
| `olivia.png` | 올리비아 · 행동 심리학 교수 (공감의 현자) |

## 권장 사양

- 형식: PNG, **배경 투명**
- 크기: 768 × 1024 (3:4 세로). 더 커도 되지만 파일당 500KB 이하 권장
- 구도: 전신 또는 무릎 위, 정면. 시선은 정면 또는 살짝 측면
- 조명: 부드러운 키라이트 + 약한 림라이트. 배경은 비우고 인물만
