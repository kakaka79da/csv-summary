# 길드 오피스 — AI-휴먼 협업 워크스페이스 (MVP)

대표 1명과 AI 직원 3명이 회사를 세우고 첫 프로젝트를 끝내는 흐름을 처음부터 끝까지
동작하는 프론트엔드로 구현한 것입니다. AI 직원은 채팅창이 아니라 오피스를 실제로
걸어 다니는 캐릭터로 표현되며, 게임 연출과 **실제 업무 상태·비용·승인 여부를 항상 함께**
표시합니다.

```
대표 로그인 → 회사 창립 → 사무실 생성 → AI 직원 3명 영입
   → 직원별 1:1 면담 → API 연결 마법사(10단계) → 첫 공동 미션 → 최종 보고 → 대표 승인
```

## 실행

```bash
cd guild-office
npm install
npm run dev          # http://localhost:5173
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm test` | 자동 테스트 23개 (상태 머신 / 경로탐색 / 승인·예산 규칙) |
| `npm run typecheck` | 타입 검사 |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 확인 |

첫 화면에서 **회사 대표 (CEO)** 데모 로그인을 누르면 창립 튜토리얼이 시작됩니다.
기본값(크림바스켓 / 강민호 / 한국 본사 / KRW)이 채워져 있으므로 그대로 진행해도 됩니다.

## 기술 구성

React 18 · TypeScript · Tailwind CSS · Framer Motion · Zustand · Vite · Vitest

오피스는 2D 탑다운 SVG로 구현했습니다. 아이소메트릭 전환 시
`components/office/OfficeCanvas.tsx` 의 좌표 변환만 교체하면 되고,
나머지 로직(경로탐색·상태 머신)은 그대로 재사용됩니다.

### 배경 컨셉 — 농장형 오픈에어 캠퍼스

실내 칸막이 대신 야외 업무 캠퍼스로 그렸습니다. 통행 규칙이 그림으로 설명된다는 점이
중요합니다 — 못 지나가는 곳은 전부 눈에 보이는 물건입니다.

| 화면 | 실제 의미 |
|---|---|
| 목재 데크 | 업무 공간 (방) |
| 자갈길 | 이동 경로 |
| 텃밭 화단 | 통과 불가 (방 경계) |
| 나무 울타리 | 캠퍼스 바깥 경계 |
| 과수원·밭·흙길 | 배경 (상호작용 없음) |

방마다 소품이 다릅니다 — 연구실은 온실, 낚시터는 연못과 부교, 휴게실은 그늘나무·해먹·
벤치·화덕, API 연결실은 태양광 패널과 케이블, 훈련장은 트랙터, 던전 입구는 봉인된 돌문.
소품 정의는 `components/office/scenery.tsx` 한 곳에 모여 있습니다.

## 설계에서 지킨 두 가지 원칙

### 1. 화면과 실제 상태가 어긋날 수 없게 만든다

캐릭터 상태는 `agentMachine.ts` 의 전이표를 통과한 값만 가질 수 있습니다.
화면은 그 값을 **그리기만** 합니다. 허용되지 않은 전이는 `null` 을 돌려주므로
"애니메이션만 바뀌고 실제 업무는 그대로"인 상황이 구조적으로 불가능합니다.

몬스터 체력 같은 연출 값은 항상 실제 진행률에서 파생됩니다. 반대 방향은 없습니다.

```ts
step.progress += (dt / step.estSeconds) * 100;        // 원본
step.monster.hpPercent = 100 - step.progress;          // 파생
```

### 2. 승인 없는 유료 작업은 시작조차 하지 않는다

시뮬레이션 루프(`advanceWorld`)는 `awaiting_approval` / `blocked` 상태의 미션을
아예 진행시키지 않습니다. 따라서 원장에 비용이 기록될 수도 없습니다.
이 규칙은 테스트로 고정되어 있습니다.

```
✓ 승인 없는 유료 작업은 시작되지 않고 비용도 발생하지 않는다
✓ 휴직 중인 직원에게는 업무를 배정할 수 없다
✓ 회사 월간 예산을 넘기면 미션이 중단되고 승인 요청이 생긴다
```

## 보안 — 이 프로토타입이 하지 않는 것

- 공용 마스터 암호 없음
- 프론트엔드에 저장된 관리자 암호 없음 (로그인 화면에 **암호 입력란 자체가 없음**)
- LocalStorage에 API 키 없음 (**키를 입력받는 UI가 없음**)
- 하드코딩된 결제·인증 토큰 없음
- `.env` 는 `.gitignore` 로 차단, `.env.example` 에는 이름과 형식만

API 연결 후 상태에 남는 것은 서버 참조 ID(`keyRef`)와 마스킹 문자열뿐이며,
`npm test` 가 상태를 직렬화해 실제 키 형태가 없는지 검사합니다.

현재 한계(인증 없음, 클라이언트 측 예산 차단 등)와 해결 방법은
[`docs/SECURITY.md`](docs/SECURITY.md) 에 정리했습니다.

## 세계관 매핑

연출은 리니지 계열 고전 판타지의 분위기에서 착안했으나, 특정 게임의 캐릭터·의상·로고·
몬스터·배경·UI를 복제하지 않고 도형만으로 새로 그렸습니다.

| 게임 표현 | 실제 의미 |
|---|---|
| 길드 / 왕국 | 회사 |
| 길드 마스터 | 대표 (최고 승인권자) |
| 일반 · 정예 · 보스 몬스터 | 일반 업무 · 복잡한 업무 · 대규모 프로젝트 |
| 레이드 | 여러 AI가 참여하는 협업 프로젝트 |
| 던전 | 프로젝트 공간 |
| 전리품 · 결과 상자 | 분석 보고서 · 문서 등 산출물 |
| 마력 코어 · 지식의 수정 | AI 제공자 API 연결 |
| 마나 · 에너지 | 남은 비용/토큰 예산 |
| 봉인 해제 · 출정 승인 | 대표 승인 |
| 전투 실패 · 장비 이상 | 업무 오류 |
| 퀘스트 완료 문서 | 최종 보고서 |

화면에서는 이 두 열을 **항상 나란히** 표시합니다.

### 캐릭터

직군마다 실루엣이 다릅니다 (`components/office/CharacterSprite.tsx`).

| 직원 | 디자인 |
|---|---|
| 세라 · 총무 매니저 | 네이비 정장, 낮은 시뇽, 이어피스, 홀로그램 태블릿 |
| 루온 · 수석 연구 엔지니어 | 회로가 빛나는 롱코트, 스마트 글래스, 장갑, 홀로그램 패널 |
| 미르 · 행동 심리학 교수 | 실크 블라우스와 펜슬 스커트, 긴 웨이브 머리, 떠다니는 문서와 빛 구슬 |
| 대표 | 금장 트림 예복 (창립 시 4가지 외형 중 선택) |

모두 도형만으로 새로 구성했으며, 특정 작품의 캐릭터·의상·로고를 복제하지 않았습니다.
