## 3단계 — 규칙 검증 (가장 중요)

| # | 확인 항목 | 기대 결과 | 자동 테스트 |
|---|---|---|---|
| 18 | 새로고침 후 상태 복원 | 회사·직원 위치·미션·비용이 그대로 | 브라우저 확인 |
| 19 | 승인 없는 유료 작업 차단 | 미션이 `대표 승인 대기` 에서 멈추고 **원장에 비용 0** | `store.test.ts` 승인 게이트 |
| 20 | 휴직 중 직원에게 배정 차단 | 업무 지시 버튼이 막히고 사유가 표시됨 | 〃 |

### 19번 수동 재현 방법
1. 직원 패널 → `API 설정` → 작업당 한도를 `0.01` 로 낮춘다 (인하는 즉시 반영).
2. `업무 지시` 탭에서 아무 업무나 `복잡한 업무` 로 지시한다.
3. 미리보기에 **승인 필요: 예** 와 사유가 나타나야 한다.
4. 지시 후 `비용 · API 사용량` 을 열어 **원장이 비어 있는지** 확인한다.
5. `대표 승인 센터` 에서 승인하면 그때부터 진행되고 비용이 기록된다.

### 20번 수동 재현 방법
1. 직원 패널 하단 `휴직 요청 (승인 필요)` 클릭.
2. `대표 승인 센터` 에서 승인 → 캐릭터 상태가 `원정 부재 · 휴직 중` 으로 변경.
3. `업무 지시` 탭 → 미리보기에 `휴직 중인 직원에게는 업무를 배정할 수 없습니다` 표시.
4. 지시 버튼이 비활성화되어야 한다.

## 추가로 확인해 볼 것

- **연출과 실제의 일치**: 캐릭터가 걷는 중인데 라벨이 `휴식 중` 이면 버그입니다.
  상태는 `agentMachine.ts` 의 전이표를 통과한 값만 사용합니다.
- **업무 중단**: 진행 중 미션을 중단하면 전투도 함께 멈추고 담당자가 대기로 돌아가야 합니다.
- **예산 초과**: 회사 월간 예산을 아주 낮게 잡고 미션을 돌리면, 중간에 멈추고
  `예산 초과 업무 재개` 승인 요청이 생겨야 합니다. (`store.test.ts` 가 검증)
- **감사 로그**: 로그인·창립·연결·승인·중단이 모두 기록되어야 합니다.
